# Messaging UI

> 카테고리: SLDS 2 디자인 패턴 · [공식](https://www.lightningdesignsystem.com/2e1ef8501/p/468e9d)

실시간·비동기 텍스트 기반 고객 대화를 위한 원칙(대화 게시자, 메시지 항목, 메시징 스타일링, 접근성 등).

> ⚠️ 크롤링 시점에 이 패턴의 상세 페이지가 SLDS 2 사이트에서 본문 없이 홈으로 리다이렉트되었습니다(미게시/준비 중으로 보임). 관련 컴포넌트는 `lightning-input-rich-text`(게시자)와 채팅 블루프린트(`blueprints/` 의 Chat)를 참고하세요. SLDS 1에는 Messaging UI 가이드(Conversation Publishers, Message Entries, A Conversation, Styling, Accessibility)가 별도로 있습니다.
