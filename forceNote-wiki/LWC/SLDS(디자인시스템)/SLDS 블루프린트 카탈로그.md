# SLDS 블루프린트 카탈로그

> SLDS **블루프린트(CSS 전용 HTML/CSS 스캐폴딩)** 30종 카탈로그. 동작·접근성(ARIA/키보드)이 없으므로, **가능하면 Lightning Base Component를 먼저 검토**하고 블루프린트는 대응 컴포넌트가 없을 때만 사용한다.

> [!warning] 블루프린트는 스타일 전용이라 JS·상호작용·접근성을 직접 구현해야 한다. 각 블루프린트의 실제 마크업·클래스·접근성 가이드는 공식 SLDS 1 문서(아래 링크)에 있다. 본 카탈로그는 인덱스/포인터 용도다.

---

## 블루프린트 vs Lightning Base Component

| 상황 | 선택 |
|---|---|
| 대응 Lightning Base Component가 있음 | **컴포넌트 우선** (동작·접근성·SLDS 2 테마 자동) |
| 컴포넌트가 없고 정적 표시만 필요 | 블루프린트 + 직접 접근성 구현 |
| SLDS 2 테마/다크모드 커스터마이즈 | 스타일링 훅(`--slds-*`)으로 조정 → [[SLDS 스타일링 훅]] |
