# Marketing Cloud 개요

> 메시징·웹 콘텐츠 설계, 고객 참여(engagement) 추적, 복잡한 마케팅 캠페인 자동화를 AI로 돕는 제품군. B2C 중심 **Engagement**와 B2B 중심 **Account Engagement**(구 Pardot), 그리고 신형 **Growth** 라인이 있다.

---

## 제품 구성

Marketing Cloud는 마케팅 활동을 지원하는 여러 라인으로 구성된다. 아래는 큰 그림이다.

```
// 구조 예시 — Marketing Cloud(실제 원본 다이어그램 아님)
Marketing Cloud Engagement (B2C): 메시징·웹 콘텐츠·캠페인 자동화(AI)
   Setup · Package Manager · delivery 추적(Sent/Not Sent)
Marketing Cloud Account Engagement (B2B, 구 Pardot): lead 육성·스코어링
Marketing Cloud Growth / Next: 신형 라인
```

## Marketing Cloud Engagement (B2C)

메시징·웹 콘텐츠를 설계하고, 고객 engagement를 조직·추적하며, 복잡한 마케팅 캠페인을 자동화하는 앱을 제공한다. **AI 기반** engagement marketing 도구다.

- **Setup** — Marketing Cloud Engagement Setup은 계정을 보고 관리하는 중앙 위치다.
- **Package Manager** — 회사/산업별 솔루션을 bundle해 business unit에 배포하여 best practice를 스케일한다.
- **규정 준수 / 추적** — SMS·transactional email의 delivery 정보와 최종 delivery status(Sent / Not Sent)를 캡처한다.

## Marketing Cloud Account Engagement (B2B, 구 Pardot)

**B2B** 마케팅 자동화 제품이다. Salesforce와 연동해 lead 육성(nurturing)·스코어링(scoring)을 수행한다. 이전 명칭은 **Pardot**이다.

## Marketing Cloud Growth / Next

신형 마케팅 라인으로, Account Engagement / Engagement의 후속·통합 방향이다.

> 각 제품의 상세 설정·기능은 [공식 문서](https://help.salesforce.com/s/articleView?id=mktg.mc_overview_marketing_cloud.htm&type=5)를 참조한다. 이 노트는 개요이며 세부는 공식 문서에 위임한다.
