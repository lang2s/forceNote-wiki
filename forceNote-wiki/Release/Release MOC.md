## 릴리즈 일정

```
Winter (N+1) → 10월 출시  (예: Winter '26 = 2025년 10월)
Spring (N)   → 02월 출시  (예: Spring '26 = 2026년 02월)
Summer (N)   → 06월 출시  (예: Summer '26 = 2026년 06월)
```
