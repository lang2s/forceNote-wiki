# TCS — Lightning Web Component 시나리오 질문

1. **Apex 메서드 예외 처리** — 의미 있는 피드백? imperative vs @wire 오류 처리 차이? 오류 시 컴포넌트 반응성 유지?
2. **이름으로 Account 검색바(동적 결과)** — 디바운싱으로 과도 Apex 호출 방지? 대용량 검색 최적화? "결과 없음" 표시?
3. **Platform Event 실시간 알림** — LWC에서 이벤트 구독? Platform Event 제약·처리? 새 이벤트마다 토스트?
4. **차트로 판매 데이터 대시보드(필터)** — Chart.js/D3.js 통합? 사용자 입력에 차트 데이터 동적 바인딩? 반응형?
5. **다국어 지원(로케일 기반 라벨)** — Custom Labels 활용? 동적 라벨 조회·표시? RTL(아랍어·히브리어) 고려?
6. **다중 선택 Contact 벌크 업데이트** — Lightning Data Table 다중 선택? 효율적 벌크 Apex? 성공·실패 피드백?
7. **데드라인 카운트다운 타이머** — LWC 타이머 구현? 성능 문제 없는 실시간 업데이트? 데드라인 변경 엣지 케이스?
8. **Case 레코드에서 Chatter 게시** — Connect API로 게시? 첨부·리치 텍스트? 최근 게시 동적 새로고침?
9. **사용자 입력 기반 자식 컴포넌트 동적 렌더링** — 부모→자식 데이터 전달? 커스텀 이벤트로 자식→부모? 다중 자식 동시 업데이트?
10. **이벤트 관리 캘린더** — 데이터 기반 동적 표시? 드래그앤드롭 재스케줄? 시간대 차이 처리?
11. **막대 클릭으로 필터링 바 차트** — Chart.js/D3.js 통합? 차트 상호작용 이벤트 핸들러? 접근성?
12. **컴포넌트 A→B 데이터 전송(독립 컴포넌트)** — Lightning Message Service(LMS)? 디커플링 유지? 메시지 디버깅?
13. **장기 작업 진행 바** — 작업 진행 상태 조회? 동적 업데이트? 실패·타임아웃 처리?
14. **워크플로우 시각화 시뮬레이터** — 워크플로우 구조 동적 표현? 실행 경로 강조? 복잡 분기 확장성?
15. **다중 사용자 실시간 협업** — Platform Events/Streaming API? 충돌 업데이트 처리? 변경 시각 표시?
16. **권한 기반 탭 인터페이스** — 탭 콘텐츠 동적 표시? 지연 로딩? 미인가 접근 차단?
17. **커스텀 데이터 테이블 인라인 편집** — 클라이언트 변경·배치 업데이트? 저장 전 검증? 다른 사용자 반영?
18. **다중 파일 업로드(진행 추적)** — 개별 진행 추적? 크기·타입 제한? 레코드 연결?
19. **권한 기반 네비게이션 바** — 동적 관리? 미인가 메뉴 숨김? 외부·내부 링크?
20. **소셜 미디어 게시(Twitter·LinkedIn)** — OAuth 인증? 민감 데이터 노출 방지? API 한도·연결 오류?
21. **Kanban 보드(드래그앤드롭)** — 레코드 분류? 드래그앤드롭? 이동 후 실시간 백엔드 업데이트?
22. **선택 필드로 레코드 복제** — 필드 선택 UI? 종속 필드 로직? 권한 부족 오류?
23. **자동완성 검색바** — 디바운스? 일치 없음 처리? 대용량 효율 표시?
24. **동적 테마 선택(라이트·다크)** — CSS 클래스 동적 적용? 세션 간 유지? 테마별 자산(이미지·아이콘)?
25. **레코드 복제 + 기본값 프리필** — 데이터 조회·폼 프리필? 역할·프로필 종속 값? 오류 처리?
26. **선택 Contact 대량 이메일** — 이메일 템플릿 선택? 한도 내 throttling? 전달·실패 추적?
