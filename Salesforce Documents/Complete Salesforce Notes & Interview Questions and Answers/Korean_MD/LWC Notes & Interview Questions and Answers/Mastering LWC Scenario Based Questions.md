# LWC 마스터 — 실전 시나리오 면접 질문

> [!warning] 제3자 학습노트(면접 Q&A)를 한글로 변환한 **Tier 3** 자료입니다. 공식 소스와 대조되지 않았으니 정확도는 공식 문서로 검증하세요.

> 원본은 이미지 PDF로 OCR 추출했습니다.

- **두 사용자가 같은 레코드 동시 편집** — 한 사용자가 다른 변경을 덮어쓰지 않게 방지? Optimistic vs Pessimistic locking 차이? 충돌 변경 알림?
- **모든 관련 레코드를 한 번에 로드해 페이지 느림** — 지연 로딩? 렌더링 최적화 라이프사이클 훅? requestAnimationFrame?
- **사용자 상호작용 기반 동적 탭** — 동적 탭 시스템? 접근성·모바일 친화? 페이지 이동 시 선택 유지?
- **일정 시간 후 자동 액션** — setTimeout·setInterval 효과적 사용? 세션 타임아웃과 간섭 방지?
- **로그인 없이 공개 접근하나 안전한 LWC** — 게스트 사용자 보안? 게스트의 with/without sharing 영향?
- **WhatsApp 메시지 발송** — WhatsApp API 통합? 메시지 상태(sent·delivered·read) 추적?
- **오프라인 동작 LWC** — 오프라인 모드 구현? 연결 복원 시 동기화?
- **AI 챗봇(Dialogflow·OpenAI)** — LWC 통합? 실시간 대화 효율 처리?
- **라이트·다크 모드 전환** — 동적 테마 전환? 사용자 선호 저장? 색 대비·접근성?
- **예측 분석으로 제품 추천** — AI/ML 모델 통합? 과거 데이터 처리?
- **이력서 파싱** — AI 이력서 파서 API 통합? 구조화 데이터 저장?
- **생체 인증(지문·얼굴)** — 생체 인증 통합? 안전 저장·검증? 대체 인증?
- **실시간 주식 시세** — 외부 주식 API 통합? 라이브 스트리밍? 과거 추세 차트?
- **현장 팀 지오펜싱 알림** — 위치 추적? Google Maps 지오펜싱?
- **블록체인 디지털 서명** — 블록체인 API 통합? 법적 구속력?
- **얼굴 인식 출퇴근** — 얼굴 인식 API? 스푸핑 방지?
- **드래그앤드롭 워크플로우 디자이너** — 드래그앤드롭 UI? 커스텀 워크플로우 저장·실행?
- **실시간 협업 화이트보드** — 실시간 화이트보드? 다중 사용자 동기화? Undo/Redo?
- **게임화 직원 교육** — 리더보드·배지·보상? 진행 추적? 소셜·동료 챌린지?
- **SSO 경험** — OAuth 2.0·SAML SSO? 안전 인증·세션 관리? 다중 시스템 역할·권한?
- **실시간 리스크 관리** — 동적 리스크 스코어링? 실시간 리스크 데이터?
- **Salesforce 내 CMS** — 커스텀 CMS? 콘텐츠 분류·태깅·검색?
- **직원 성과 관리** — 성과 관리 시스템? 목표 설정·진행·피드백?
