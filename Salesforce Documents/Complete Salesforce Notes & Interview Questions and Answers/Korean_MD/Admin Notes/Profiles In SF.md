# Salesforce의 프로필(Profiles)

## 개요

- **정의:** 프로필은 사용자가 데이터, 오브젝트, 필드, 기타 Salesforce 기능에 갖는 접근 수준을 정의합니다.
- **목적:** 사용자 권한, 오브젝트·필드 수준 보안, 레코드 접근 등을 제어합니다.
- **중요성:** 사용자 역할에 따라 접근을 제한·부여하여 보안, 데이터 프라이버시, 맞춤형 사용자 경험을 보장합니다.

## 1. 프로필이란?

- 사용자가 Salesforce에서 무엇을 보고, 수정하고, 생성할 수 있는지 제어합니다.
- 모든 사용자는 프로필을 할당받습니다.
- 앱·탭·레코드 등 기능 접근을 정의하고 플랫폼 전반의 권한을 결정합니다.

## 2. 프로필 유형

- **표준 프로필(Standard):** Salesforce가 기본 제공. 예: System Administrator, Standard User, Read-Only, Marketing User.
- **커스텀 프로필(Custom):** 조직 요구에 맞게 생성. 권한, 접근 설정, 오브젝트 권한 커스터마이징.

## 3. 프로필의 구성 요소

- **오브젝트 권한:** 표준·커스텀 오브젝트의 Read, Create, Edit, Delete 권한.
- **필드 수준 보안:** 사용자가 어떤 필드를 보거나 편집할 수 있는지 결정.
- **사용자 권한:** Setup 기능, 레코드 관리 등에 대한 접근.
- **탭 설정:** 어떤 탭이 표시되거나 숨겨지는지 정의.
- **레코드 타입 접근:** 어떤 레코드 타입을 보고 생성할 수 있는지 제어.
- **로그인·세션 설정:** 로그인 시간, IP 범위 제한 등.

## 4. 프로필 관리

- **커스텀 프로필 생성:** Setup → Profiles → New Profile. 기존 표준 프로필(예: System Admin) 기반으로 생성.
- **프로필 편집:** 필요에 따라 권한, 오브젝트 접근, 필드 가시성 조정.
- **사용자에게 할당:** 사용자 생성 시 또는 이후에 할당.

## 5. 프로필 vs 권한 집합

- **프로필:** 사용자의 기준 권한 제어. 사용자에게 할당 필수이며 "쌓을(stack)" 수 없음.
- **권한 집합:** 프로필에 정의된 것 위에 추가 권한 제공. 프로필 변경 없이 할당 가능.

## 6. 프로필 관리 모범 사례

- 세분화된 접근에는 권한 집합 사용(복잡한 프로필 회피)
- 프로필 수 제한(유사 프로필 통합)
- 민감 데이터에 광범위한 접근 부여 금지(업무에 필요한 데이터만)
- 정기적으로 프로필 검토(규정 준수·관련성 확인)
- 표준 프로필을 템플릿으로 사용

## 7. 결론

프로필은 사용자 권한, 데이터 접근 관리와 Salesforce 환경 보안에 핵심적입니다. 정기적으로 검토·업데이트하고, 세분화된 접근 제어에는 권한 집합을 활용하세요.
