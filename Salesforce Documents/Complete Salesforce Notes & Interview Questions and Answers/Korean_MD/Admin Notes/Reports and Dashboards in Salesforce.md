# Salesforce의 리포트와 대시보드

Salesforce는 데이터를 시각화·분석할 수 있는 강력한 리포트·대시보드 도구를 제공합니다.

## 리포트(Reports)

**리포트란?** 하나 이상의 오브젝트에서 수집된 레코드 모음으로 표 형식으로 표현합니다. "대시보드"의 도움으로 그림 형식으로도 표현할 수 있으며, 관련 데이터를 표시·그룹화·필터링·요약하도록 커스터마이징할 수 있습니다.

**유형:**
1. **표준 리포트:** Salesforce가 CRM의 일부로 기본 제공(Sales, Service, Marketing 관련).
2. **커스텀 리포트:** 관리자·개발자가 요구사항에 따라 자체 구성(일간/주간/월간/분기별 구성 가능).

**리포트 폴더:** 각 리포트는 폴더에 저장됩니다.
- **표준 폴더:** 기본 제공(Unfiled Custom Reports, Sales Report, Account Report 등).
- **커스텀 폴더:** 개발자·관리자가 생성(Banking Report Folder 등).

**리포트 구성 매개변수:** 리포트 타입, 표시할 필드, 필드 순서, 필터 조건, 차트 컴포넌트, 예약 정보.

## 커스텀 리포트 유형

### Tabular Report
가장 단순한 형식으로 그룹화 없이 행으로 데이터 표시. 필드는 열로 정렬. 차트 컴포넌트로 표현 불가.

리포트 생성 시 필터 유형:
1. **Field Filter:** 오브젝트 필드 기반 필터 조건 추가.
2. **Cross Filter:** 관련 오브젝트에 조건을 추가해 레코드 조회.
3. **Row Limit Filter(Classic 전용):** 표시 레코드 수 제한(Lightning에서는 불가).

사용 시점: 레코드 빠른 접근, 여러 레코드 업데이트, 데이터 빠른 내보내기·공유. 그룹화·요약 없음.

### Summary Report
지정된 필드로 데이터 그룹화. 최대 3단계 그룹화 가능. 차트 컴포넌트로 표현 가능, 주기적 예약 실행 가능.

사용 시점: 특정 필드별 데이터 분석, 핵심 지표 요약, 레코드 그룹 간 비교, 기간별 분석. 합계·평균·최소·최대 등 요약, 조건부 강조 적용 가능.

### Matrix Report
행과 열 모두로 데이터 그룹화(다차원 레이아웃). 관련 합계 비교에 유용.

사용 시점: 여러 차원 분석(예: 시간 경과에 따른 담당자별 매출), 고도로 커스터마이징된 리포트. 행·열 소계와 총계 지원, 대시보드 사용 가능. 설정·해석에 더 많은 노력 필요.

### Joined Report
여러 리포트 데이터를 단일 리포트로 결합. 여러 블록 추가 가능(각 블록에 다른 조건·필터·필드). 최대 5개 블록. 차트 형식 불가, 예약 불가.

사용 시점: 서로 다른 오브젝트 데이터 분석(Account·Opportunity 수준), 한 탭에 다른 리포트 형식 포함, 분기별 성과 검토 같은 고수준 개요.

## 대시보드(Dashboards)

**대시보드란?** Salesforce 리포트 데이터를 기반으로 핵심 지표와 추세를 시각적으로 표시. 차트·표·게이지 형태로 한눈에 데이터를 모니터링·분석하도록 돕습니다. 각 컴포넌트가 리포트의 데이터를 나타냅니다.

**대시보드 컴포넌트:**

1. **차트(Charts):** 데이터 추세·비교·패턴 시각화.
   - Bar Chart: 가로/세로 막대로 값 표시. 예: 지역별 매출, 단계별 Opportunity.
   - Pie Chart: 원을 세그먼트로 나눠 비율 표시. 예: 제품별 매출 분포.
   - Line Chart: 시간 경과 추세를 선으로 표시. 예: 시간별 매출 성장.
   - Donut Chart: 가운데 구멍이 있는 파이 차트로 총합 표시. 예: 제품별 매출 분석.

2. **테이블(Tables):** 리포트 데이터를 표 형식으로 표시. 예: 열린 Opportunity 표(Account명, 마감일, 단계, 금액). 차트보다 세분화된 데이터 제공.

3. **게이지(Gauges):** 범위 내 단일 값을 표시해 목표 진행률 시각화. 예: 영업 할당량 달성률(75%). 최소·최대·중간값으로 임계값(Low, Medium, High) 정의.

4. **메트릭(Metrics):** 단일 핵심 값 표시. 예: 총 매출, 열린 Opportunity 수, 활성 고객 수. 단순·직관적(차트·그룹화 없음).

5. **Visualforce 컴포넌트:** Visualforce로 구축한 커스텀 대시보드 컴포넌트. 예: 커스텀 영업 리더보드, 대화형 지도. 완전 커스터마이징 가능(코딩 필요).

## 핵심 팁

**리포트:** Tabular(빠른 데이터 뷰), Summary(KPI 추적), Matrix(행·열 비교 심층 분석), Joined(여러 데이터셋 결합).

**대시보드:** Charts(추세 시각화), Tables(상세 데이터), Gauges(목표 진행률), Metrics(단일 숫자 통계), Custom Visualforce Components(맞춤 솔루션).
