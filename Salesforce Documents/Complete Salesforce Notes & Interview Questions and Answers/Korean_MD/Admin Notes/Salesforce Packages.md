# Salesforce의 패키지(Packages)

- 패키지는 개별 컴포넌트처럼 작은 것부터 관련 앱 세트처럼 큰 것까지 담는 컨테이너입니다.
- 패키지를 만든 후 회사 외부를 포함한 다른 Salesforce 사용자·조직에 배포할 수 있습니다.

## Managed Package(관리형 패키지)

종속 요소와 긴밀히 통합된 메타데이터 컴포넌트의 큐레이팅된 모음입니다. 주로 salesforce.com 파트너가 고객에게 애플리케이션을 배포·판매하는 데 사용합니다. Developer Edition 조직에서 생성되며 AppExchange를 통해 배포할 수 있어, 개발자가 License Management Application(LMA)을 통해 사용자 기반 라이선스를 판매·관리할 수 있습니다.

특징:
- Apex에 대한 지식재산권 보호
- API 접근 가능 컴포넌트의 내장 버전 관리
- 이전 버전 분기·패치 기능
- 구독자에게 매끄러운 푸시 업데이트
- 고유 컴포넌트 명명으로 충돌 없는 설치
- 완전 업그레이드 가능(단, 매끄러운 업그레이드를 위해 오브젝트·필드 제거 같은 파괴적 변경은 불가)

## Unmanaged Package(비관리형 패키지)

생성한 개발자와 설치하는 설치자 모두가 편집할 수 있는 메타데이터 컴포넌트 모음입니다. 관리형 패키지와 달리 설치 후 업그레이드할 수 없습니다. 보통 일대일 배포(특정 컴포넌트·기능을 다른 조직과 공유)에 사용됩니다.

**비관리형 패키지 생성 예:**
1. Setup → "package" 검색 → Package Manager
2. New로 새 패키지 생성 후 저장
3. Add Component → 원하는 컴포넌트 선택(예: Flow Definition → 스크린 플로우 추가)
4. 패키지 업로드(필요 시 비밀번호 설정)
5. 생성된 링크를 원하는 사람과 공유
6. 대상 조직에 설치하고 관리자나 모든 사용자에게 권한 부여
7. 설치 후 필요에 따라 사용·편집
