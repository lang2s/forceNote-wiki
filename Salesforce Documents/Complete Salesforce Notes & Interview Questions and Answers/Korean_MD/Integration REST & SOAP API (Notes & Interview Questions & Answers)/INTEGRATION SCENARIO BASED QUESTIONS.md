# 통합 시나리오 기반 질문

## Q: 외부 시스템에서 대량 데이터(예: 100만 건)를 Salesforce로 처리·통합. Batch Apex 작성
**의도:** Batch Apex·대량 데이터·성능 최적화·거버너 한도·오류 처리 이해.
**자주 막히는 부분:** 대량 데이터 최적화(청크 크기·쿼리) 미흡, 콜아웃 한도·타임아웃 미처리, 오류 처리·재시도 로직 부재.

## Q: Salesforce와 Google API(Drive·Calendar) 통합. Drive에 파일 업로드 코드
**의도:** OAuth 2.0·파일 업로드·서드파티 API 이해. 토큰 관리·API 할당량.

## Q: 통합 코드 테스트 클래스 작성. REST API 콜아웃 테스트 클래스
**의도:** 단위 테스트·Mock 콜아웃·커버리지 이해.
**자주 막히는 부분:** HttpCalloutMock 미사용, 100% 커버리지 실패, 의미 있는 assertion 부재.
