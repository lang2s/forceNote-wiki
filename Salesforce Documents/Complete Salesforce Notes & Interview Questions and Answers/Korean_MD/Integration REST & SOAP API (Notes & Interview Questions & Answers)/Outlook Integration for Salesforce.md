# Salesforce와 Outlook 통합

## 소개
Office 365와 Salesforce 통합으로 생산성·프로젝트 관리·커뮤니케이션 향상.

## 전제 조건
Microsoft 365 계정, Salesforce 계정.

## 단계
**1. Salesforce에서 Outlook 선택:** Setup → Quick Find에 "Outlook" → "Outlook Integration and Sync" → 토글 켜기.

**2. Salesforce 구성:** Microsoft AppSource에서 Outlook용 Salesforce 추가 기능 다운로드 → Get it now → Continue → Open in Outlook web.

**3. Outlook과 통합:** 메일에서 앱 아이콘 → Salesforce 앱 → Production/Sandbox 선택 → Confirm으로 연결. 이제 Outlook에 Salesforce 패널 활성화(Contact·Task·Event 생성).

**4. Outlook에서 레코드 생성·조회:** + 아이콘 → 오브젝트 선택 → 레코드 생성. 기존 레코드 검색도 가능.

## 결론
이메일과 Salesforce 데이터를 통합 플랫폼에서 관리해 워크플로우 효율 향상, 상호작용 추적·레코드 생성 용이.
