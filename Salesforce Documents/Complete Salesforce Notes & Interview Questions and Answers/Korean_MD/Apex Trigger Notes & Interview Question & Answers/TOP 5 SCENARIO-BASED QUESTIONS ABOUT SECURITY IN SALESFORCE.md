# Salesforce 보안 관련 시나리오 기반 질문 TOP 5

**Q1. 영업팀과 마케팅팀에서 각각 한 명의 사용자가 있습니다. 두 사람 모두 같은 Account에 접근해야 하지만 서로 다른 필드를 봐야 합니다. Salesforce에서 어떻게 구성하시겠습니까?**

- **프로필(Profiles):** 영업팀과 마케팅팀을 위한 별도의 프로필을 생성합니다.
- **필드 수준 보안(Field-Level Security):** 프로필에 따라 필드 가시성을 설정합니다.
- **페이지 레이아웃(Page Layouts):** 각 프로필에 서로 다른 페이지 레이아웃을 할당하여 사용자가 관련 필드만 보도록 합니다.
- **공유 규칙(Sharing Rules):** 두 팀이 같은 Account 레코드에 접근하되 적절한 필드 수준 제한을 받도록 공유 규칙을 사용합니다.

**Q2. 관리자는 자기 팀원이 소유한 모든 Opportunity를 봐야 하지만, 개별 팀원은 자신의 레코드만 봐야 합니다. 공유 모델을 어떻게 구성하시겠습니까?**

- **조직 전체 기본값(OWD):** Opportunity를 "Private(비공개)"로 설정합니다.
- **역할 계층(Role Hierarchy):** 관리자가 역할 계층에서 상위에 위치하도록 하여 팀의 Opportunity에 대한 접근 권한을 상속받게 합니다.
- **공유 규칙(Sharing Rules):** 추가 접근이 필요한 경우(예: 팀 간 공유) 특정 그룹이나 역할에 대해 공유 규칙을 구성합니다.

**Q3. 신규 사용자가 동료와 같은 프로필을 가지고 있는데도 커스텀 오브젝트에 접근하지 못합니다. 무엇이 문제일 수 있나요?**

- **권한 집합 확인(Permission Sets):** 해당 오브젝트에 대한 접근을 제공하는 필요한 모든 권한 집합이 사용자에게 할당되었는지 확인합니다.
- **레코드 수준 보안:** 공유 규칙이나 수동 공유를 통해 사용자가 레코드에 접근할 수 있는지 확인합니다.
- **프로필 비교:** 프로필이 정말 동일한지, 특히 오브젝트 수준 권한을 다시 한번 확인합니다.

**Q4. 사용자의 프로필을 수정하지 않고 특정 기능이나 레코드에 임시로 접근 권한을 부여해야 합니다. 어떻게 하시겠습니까?**

- **권한 집합 사용:** 필요한 접근을 부여하는 임시 권한 집합을 사용자에게 할당합니다.
- **수동 공유(Manual Sharing):** 사용자가 필요로 하는 특정 레코드라면 해당 레코드를 수동으로 공유합니다.
- **접근 모니터링:** 작업이 완료되면 권한을 제거하거나 접근을 취소합니다.

**Q5. 관리팀이 Salesforce에서 누가 데이터를 내보낼 수 있는지 모니터링하고 제한해야 합니다. 어떻게 해결하시겠습니까?**

- **프로필 설정:** 프로필에서 "Export Reports" 및 "Data Export" 권한을 비활성화합니다.
- **권한 집합:** 데이터 내보내기 권한을 승인된 사용자에게만 할당합니다.
- **이벤트 모니터링(Event Monitoring):** Event Monitoring을 사용해 리포트나 API를 통한 데이터 내보내기를 추적합니다.
