# Prompt Design Guide

> 카테고리: SLDS 2 디자인 패턴(AI) · [공식](https://www.lightningdesignsystem.com/2e1ef8501/p/0364a5-prompt-design-guide)
> 하위: Overview · Conversation vs. Prompt Design · Design Phase · Prompt Elements 등

Agentforce·Einstein 같은 도구를 위한 **명확·재사용 가능·임팩트 있는 프롬프트** 작성 가이드. (Prompt Builder, Agent Builder 사용)

## 용어
- **Prompt** — LLM에 작업을 지시하는 자연어 명령. 엔터프라이즈에선 맥락·제약 등 배후 지시까지 포함.
- **Prompt Template** — 단일·명확한 작업을 높은 신뢰도로 반복 수행하는 구조화·재사용 지시(단일턴, 다단계 추론 불필요). "전문 도구/레시피".
- **Agent** — LLM+추론으로 다단계 프로세스·대화를 처리하는 목표지향 자율 AI. "도구·레시피를 골라 쓰는 셰프".

| 구분 | Prompt Template | Agent |
|---|---|---|
| 범위 | 단일 작업(케이스 요약) | 다단계 목표(고객 이슈 해결) |
| 상호작용 | 단방향 1회 | 대화형 멀티턴 |
| 역량 | 사전 정의 텍스트 실행 | 여러 도구·액션 오케스트레이션 |
| 지능 | 프롬프트 품질에 한정 | 의도 이해·결정·행동 |

## 소비자용 vs 엔터프라이즈 프롬프트
- 공통: 명확한 지시·맥락·목표, 구체 예시, NLP, few-shot·chain-of-thought, 피드백 튜닝, LLM 한계 이해.
- 엔터프라이즈 차이: **비즈니스 프로세스·워크플로 통합**, Salesforce 데이터 구조와 호환·신뢰성, 조직 지식 반영, **거버넌스·확장** 설계. 모든 입력에 일관·신뢰 가능한 출력.

## 대상·구성
- 대상: 관리자, 프롬프트 작성자, 기술 작가, PM, UX 디자이너, 엔지니어, CS 등(초·중급).
- 제공: **프롬프트 요소(구조화된 빌딩 블록)** 프레임워크 + 모범사례·예시·재사용 패턴 + 평가·개선 방법.
- 패턴은 **영감을 주는 출발점**이지 엄격한 규칙 아님 — 작업에 맞게 변형·테스트.
- 제외: 코드/수학/시각 생성 프롬프트, 심층 기술 엔지니어링.
