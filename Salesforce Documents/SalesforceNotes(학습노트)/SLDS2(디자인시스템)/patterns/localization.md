# Localization

> 카테고리: SLDS 2 디자인 패턴 · [공식](https://www.lightningdesignsystem.com/2e1ef8501/p/962e74-localization)

콘텐츠·형식·UI 관례를 언어·지역·문화에 맞게 적응. 번역 시에도 기능하는 UI 만들기.

## 빠른 팁
- **300% 확장 대비** — 짧은 영어가 번역 시 크게 길어짐.
- **국기 대신 텍스트** — 국기는 국가이지 언어가 아님(스페인어는 29개국 사용). 언어 선택기는 plain text.
- **패딩 대신 정렬 로직** — 고정 패딩 대신 `text-align`으로 중앙 정렬.
- **문장 독립성** — 문장 중간에 입력 필드를 끼우는 "Mad Libs" UI 피하기.

## 글로벌 사용자 고려
- **색의 문화적 의미** — 빨강: 서구=경고/위험, 일부 아시아(중국·일본)=행운/행복.
- **텍스트 확장 설계** — 고정 width/height 지양, 컴포넌트 확장 가능하게. 긴 텍스트는 wrapping(세로 확장 주의), truncation+hover는 절충(효과 저하 위험).
- **라벨·인라인 폼 분리** — 언어마다 어순 달라(예: "From D1 To D2" → 일본어 "D1 から D2 まで"). 문장 중간 UI 지양, 불가피하면 콜론으로(`Start: D1  End: D2`).

## 로컬라이즈 친화 CSS
- **강제 대문자화 금지** — `text-transform` 등으로 대소문자 처리 금지(프랑스어 등은 첫 단어만 대문자). 대소문자는 번역자에게.
- **text-align 사용** — 패딩으로 중앙 정렬하면 번역 시 오버플로. `text-align` 권장.

## 텍스트 확장률 (IBM 가이드)
| 영어 길이 | 확장 |
|---|---|
| 1–10자 | 100–200% |
| 11–20 | 80–100% |
| 21–30 | 60–80% |
| 31–50 | 40–60% |
| 51–70 | 50–70% |
| 71+ | 30% |

- 언어별("Share" 기준): 독일어 1.8×, 스페인어 1.8×, 이탈리아어 1.7×, 프랑스어 1.5×, 일/중 0.8×, 한국어 0.7×. CJK는 대체로 compact하나 글자가 넓어 가로 공간을 더 쓸 수 있음(특히 일본어 가타카나).
