# PWC Sales Cloud 시나리오 질문 (3년+ 경력)

> [!warning] 제3자 학습노트(면접 Q&A)를 한글로 변환한 **Tier 3** 자료입니다. 공식 소스와 대조되지 않았으니 정확도는 공식 문서로 검증하세요.

1. **할인이 승률에 미치는 영향 분석** → Opportunity 할인율 필드, 승률 vs 할인 리포트, 트렌드 대시보드.
2. **분기 성과 대시보드(파이프라인·마감·실주)** → 분기별 Opportunity 리포트(Stage·Amount·승패 사유), 차트·테이블 대시보드.
3. **마감 외 활동 지표(통화·이메일·미팅) 추적** → Activity Tracking·커스텀 필드, 활동 vs 마감 리포트, Einstein Activity Capture.
4. **웹 폼 Lead를 제품 관심·점수 기반 라우팅** → Web-to-Lead/API, Lead Assignment Rules, Einstein Lead Scoring.
5. **후속 Task 자동 생성** → Process Builder/Flow, Einstein Activity Capture.
6. **고액 딜 리더십 승인(Deal Review)** → "Deal Review Status" 필드, 딜 가치 기준 Approval Process, 승인 전 레코드 잠금.
7. **소매·도매 다른 가격 모델** → Price Book, Account 유형별 할당, 자동화로 올바른 Price Book 적용.
8. **비관리자 특정 Opportunity 필드 접근 제한** → Field-Level Security, Permission Set/Profile, 검증 규칙.
9. **단계별 필수 필드** → 검증 규칙, Path 가이드, 조건부 Lightning 페이지.
10. **Opportunity에서 동적 가격 견적** → Salesforce CPQ, 가격 규칙, Quote Template.
11. **Closed Won 후 온보딩 추적** → 커스텀 "Onboarding" 오브젝트, 자동 태스크·마일스톤, 진행 대시보드.
12. **실시간 커미션 표시** → 커스텀 오브젝트·필드, 자동 업데이트, 대시보드.
13. **사업부별 예측(고유 할당·KPI)** → Collaborative Forecasts(부서별 forecast type), 부서별 할당, 리포트·대시보드.
14. **고객 감정 추적** → Opportunity "Sentiment" 선택 목록(Positive/Neutral/Negative), 교육, 리포트·대시보드.
15. **교육 효과 추적** → "Training Attendance" 오브젝트, 이수·인증 추적, 성과 영향 리포트.
16. **산업·매출 규모 세분화 캠페인** → Account 커스텀 필드, Dynamic Campaign, 세그먼트별 대시보드.
17. **Opportunity의 다중 Contact 역할(의사결정자·영향자·사용자)** → Opportunity Contact Roles, 커스텀 필드, 리포트·대시보드.
18. **영역 내 Account만 Opportunity 접근** → Territory Management, Sharing Rules·Role Hierarchy, 검증 규칙.
19. **참여·구매 행동 세분화** → Account·Opportunity 참여 필드, 리포트·대시보드, Einstein Analytics.
20. **파트너 생성 Opportunity 추적** → PRM, Opportunity-Partner 관계, Revenue Sharing 모델·리포트.
21. **파트너별 Opportunity·매출·승률 리포트** → PRM, Partner Account lookup, Partner Performance Report.
22. **Closed Won 3일 후 후속 이메일** → Process Builder/Flow(3일 대기 후 이메일), Email Template, Opportunity당 1회.
23. **구독 기반 매출 인식** → Revenue Recognition 또는 Subscription 오브젝트, 커스텀 리포트, CPQ 반복 청구·갱신.
24. **볼륨 기반 가격 자동 적용(CPQ)** → Price Book·Price Rules, Product Rules, Discounting Rules.
25. **Account에 관련 Opportunity 총액 표시** → Roll-Up Summary 필드(Closed Won 합산).
26. **소유자·단계별 실시간 파이프라인 리포트** → Sales Pipeline Report, 단계 필터, Dynamic Dashboard.
