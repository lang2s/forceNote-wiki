# 트리거와 Flow의 차이, 언제 무엇을 사용하나?

> [!warning] 제3자 학습노트(면접 Q&A)를 한글로 변환한 **Tier 3** 자료입니다. 공식 소스와 대조되지 않았으니 정확도는 공식 문서로 검증하세요.

- **트리거 사용:** 대량 데이터 처리, 검증 강제, 관련 오브젝트 간 복잡한 업데이트, 고성능 자동화.
- **Flow 사용:** UI 기반 자동화, 안내형 워크플로우, 예약 작업, 비개발자가 자동화를 관리하게 하고 싶을 때.
