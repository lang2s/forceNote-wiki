# LWC 트렌딩 시나리오 Q&A 2025

> [!warning] 제3자 학습노트(면접 Q&A)를 한글로 변환한 **Tier 3** 자료입니다. 공식 소스와 대조되지 않았으니 정확도는 공식 문서로 검증하세요.

1. **Apex 호출 오류 처리** — 서버 오류(권한·잘못된 입력)를 컴포넌트에 표시·재시도 UI 설계.
2. **Record Form 커스터마이즈** — lightning-record-form으로 생성·편집 폼, 커스텀 검증·성공/오류 메시지.
3. **컴포넌트 간 검증** — 부모 + 여러 자식(폼 섹션), 제출 전 전체 검증·부모에 통합 오류 표시.
4. **커스텀 차트** — 사용자별 단계별 Opportunity 막대 차트, 사용자 동적 선택·Chart.js 통합.
5. **드래그앤드롭 파일 업로드(진행)** — 특정 타입·크기 제한, 파일별 진행 바.
6. **데이터 사전 조회(성능)** — UI 렌더링 전 중요 데이터 로드, 지연 로딩 결합·로딩 스피너.
7. **그룹화 데이터 시각화** — 단계·소유자별 그룹, 접을 수 있는 형식·효율 쿼리.
8. **실시간 채팅** — Streaming API로 실시간 메시지, 성능 유지 라이브 업데이트.
9. **진행 추적 태스크 자동화** — 완료 상태 시각 추적·드래그앤드롭 재정렬.
10. **커스텀 위저드** — 다단계 가이드, 필수 입력 완료 전 다음 단계 차단·중간 저장.
11. **오프라인 데이터** — 오프라인 입력·온라인 시 동기화, 충돌 해결.
12. **컴포넌트 액션 감사 추적** — 사용자 액션을 커스텀 오브젝트에 기록(사용자·타임스탬프·변경)·성능 영향 최소화.
13. **Chatter 파일 업로드** — Chatter 피드 업로드·관련 레코드 태깅, 대용량 안전 처리.
14. **동적 SOQL 빌더** — 필터 선택 동적 쿼리, injection 방지·검증·페이지네이션.
15. **인터랙티브 조직도** — 계층 시각화·상호작용, 대형 계층 효율·클릭 이벤트.
16. **이벤트 기반 컴포넌트 업데이트** — 레코드 업데이트가 다른 컴포넌트 실시간 변경, LMS 전파·동기화.
17. **동적 Lookup** — 모든 오브젝트 동적 lookup·실시간 필터링·페이지네이션.
18. **다중 기준 필터링** — 날짜·상태·우선순위 필터, 성능·필터 초기화.
19. **실시간 알림** — 실시간 변경 감지·UI 업데이트, LMS·로드 시간 최적화.
20. **캐싱 메커니즘** — 서버 호출 회피·성능 향상, 컴포넌트 캐시·무효화·session/local storage.
21. **배치 처리 레코드 업데이트** — 조건 기반 다중 Opportunity 업데이트, 배치 트리거·완료/오류 알림.
22. **드래그앤드롭** — 상태 간 태스크 이동·재정렬, HTML5 API·접근성.
23. **진행 표시 파일 업로드** — 다중 파일·파일별 진행, 오류 처리.
24. **태그 다중 선택** — 다중 선택 드롭다운·태그 표시, 추가/제거·서버 동기화.
25. **데이터 사전 로드** — 렌더링 중 데이터 사전 로드·로더 표시·다중 소스 최적화.
26. **Chatter 통합** — 게시·좋아요·댓글, Chatter REST API·실시간 UI.
27. **커스텀 알림 배너** — 다가오는 태스크·승인 알림, 동적 조회·dismissible/자동 닫기.
28. **서버 측 페이지네이션** — 대량 데이터 청크, 한도 회피·서버 변경 처리.
29. **동적 컴포넌트 로딩** — 사용자 선호 기반 위젯, 동적 import·성능.
30. **가상 스크롤** — 긴 목록 성능 최적화, 가시 레코드만 로드.
31. **지도 통합** — Google Maps로 위치 표시, API 키 보안·다중 핀 렌더링.
32. **감사 추적 뷰어** — 레코드 변경 이력(누가·언제), 조회·페이지네이션.
33. **커스텀 파일 업로드** — 다중·드래그앤드롭, 크기·타입 제한·진행 표시.
34. **Platform Events 실시간 알림** — 이벤트 발생 시 알림(새 Opportunity), Platform Event 구독·대상 사용자 관리.
